Kontynuacja kursu [HTML5 — część 1: od podstaw](/kursy/html5-od-podstaw). Znasz już strukturę dokumentu, tekst, linki, obrazy, tabele, formularze i znaczniki semantyczne — teraz przejdziesz na **poziom zaawansowany**: strony dostępne dla wszystkich, szybkie, dobrze widoczne w wyszukiwarkach i korzystające z nowoczesnych możliwości HTML5.

## Czego się nauczysz

- optymalizować sekcję `<head>` pod **SEO** i udostępnianie w mediach społecznościowych,
- budować strony **dostępne** zgodnie z WCAG, z poprawnym użyciem **ARIA**,
- serwować **obrazy responsywne** (`srcset`, `sizes`, `<picture>`, AVIF/WebP),
- tworzyć zaawansowane **formularze** i obsługiwać ich walidację,
- korzystać z natywnych elementów interaktywnych: `<details>`, `<dialog>`, atrybut `popover`,
- rysować grafikę w **SVG** i **Canvas**,
- dodawać napisy **WebVTT** i sterować multimediami z JavaScriptu,
- tworzyć własne znaczniki — **Web Components**,
- używać API przeglądarki związanych z HTML5: `data-*`, **Web Storage**, **drag & drop**,
- dbać o **wydajność** i dodawać **dane strukturalne** (JSON-LD).

## Plan kursu — 10 części

1. Zaawansowany head: SEO, Open Graph i ikony
2. Dostępność: WCAG i ARIA w praktyce
3. Obrazy responsywne: srcset, sizes i picture
4. Zaawansowane formularze i walidacja
5. Elementy interaktywne: details, dialog i popover
6. Grafika w HTML5: SVG i Canvas
7. Zaawansowane multimedia: napisy WebVTT i Media API
8. Web Components: template, slot i Shadow DOM
9. API przeglądarki: data-*, Web Storage i drag & drop
10. Wydajność, dane strukturalne i projekt końcowy

Każda część kończy się **zadaniem praktycznym**, a kurs — **projektem końcowym** i **quizem sprawdzającym**.

## Wymagania

- ukończona [część 1](/kursy/html5-od-podstaw) lub równoważna wiedza,
- podstawy JavaScriptu przydadzą się w częściach 4–9 (przykłady są krótkie i opisane krok po kroku),
- około 15–20 godzin nauki.
