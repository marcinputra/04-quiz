HTML opisuje **treść** strony, a **CSS** (*Cascading Style Sheets*) — jej **wygląd**: kolory, czcionki, odstępy i układ. W tym kursie nauczysz się stylować strony od zera aż po nowoczesne, **responsywne układy** we Flexboxie i Gridzie, które dobrze wyglądają na telefonie i na komputerze.

## Czego się nauczysz

- jak podłączyć CSS i jak działają **selektory, kaskada i specyficzność**,
- dobierać **kolory, jednostki i czcionki**,
- panować nad odstępami dzięki **modelowi pudełkowemu**,
- używać **pseudoklas i pseudoelementów** (`:hover`, `:focus-visible`, `::before`),
- budować układy we **Flexboxie** i **CSS Grid**,
- tworzyć strony **responsywne** (mobile-first, media queries, `clamp()`),
- dodawać **przejścia i animacje** z poszanowaniem ustawień użytkownika,
- organizować kod za pomocą **zmiennych CSS** i dodać **tryb ciemny**.

## Plan kursu — 9 lekcji

1. Wprowadzenie: składnia, selektory i kaskada
2. Kolory, jednostki i typografia
3. Model pudełkowy: margin, padding, border
4. Zaawansowane selektory, pseudoklasy i pseudoelementy
5. Flexbox — układ w jednym wymiarze
6. CSS Grid — układ w dwóch wymiarach
7. Responsywność: media queries i mobile-first
8. Pozycjonowanie, transformacje i animacje
9. Zmienne CSS, tryb ciemny i projekt końcowy

Każda lekcja kończy się **zadaniem**, a kurs — **projektem końcowym** (ostylowanie strony-wizytówki z kursu HTML5) i **quizem**.
