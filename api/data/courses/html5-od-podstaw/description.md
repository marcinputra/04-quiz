Pierwsza część kursu HTML5 — dla osób, które **nigdy nie pisały stron internetowych**. Krok po kroku zbudujesz pierwszą stronę w HTML5 — od pustego pliku do kompletnej strony-wizytówki z menu, zdjęciami, tabelą i formularzem kontaktowym.

## Czego się nauczysz

- jak zbudowany jest dokument HTML5 i jak przeglądarka go czyta,
- formatowania tekstu, list i linków,
- wstawiania obrazów, dźwięku i wideo,
- tworzenia tabel i formularzy z nowymi polami HTML5,
- **semantycznego HTML5** — `header`, `nav`, `main`, `article`, `footer` — i dobrych praktyk.

## Plan kursu

1. Wprowadzenie i struktura dokumentu HTML5
2. Tekst, nagłówki, listy i linki
3. Obrazy i multimedia
4. Tabele i formularze
5. Semantyczny HTML5 i projekt końcowy

Każdy rozdział kończy się **zadaniem do samodzielnego wykonania**, a na końcu kursu czeka **quiz sprawdzający**.

## Czego potrzebujesz

- dowolnej przeglądarki (Chrome, Firefox, Edge),
- edytora tekstu — polecamy darmowy **Visual Studio Code**,
- około 5–8 godzin nauki.
